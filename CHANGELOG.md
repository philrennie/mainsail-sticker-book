# Changelog

## 1.0.0 — 2026-10-25

First release.

- Pastel "sticker" panels with their own header colours and a slight tilt that springs level on hover/focus
- Hand-drawn wobbly panel outlines with matching wobbly hard shadows (straight-sided when a panel is collapsed)
- Light mode (cream paper, ink outlines) and dark mode (plum night, chalk outlines), following Mainsail's Mode setting
- Squishy outlined buttons, chunky sliders, rounded inputs, butter-yellow top bar, pastel sidebar highlights
- Fredoka font bundled locally (no Google Fonts requests)
- `tools/squiggle.py` to regenerate the outline images in custom colours
